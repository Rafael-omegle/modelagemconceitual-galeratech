# modelagemconceitual-galeratech
Modelo conceitual de um sistema de gerenciamento de serviços para pets, representando as entidades e seus relacionamentos.

Entidades principais: Tutores, pets, lojas, funcionários, serviços e atendimentos.

Objetivo: Organizar a estrutura do sistema e servir como base para o desenvolvimento do banco de dados.

Ferramenta: BR Modelo Web
